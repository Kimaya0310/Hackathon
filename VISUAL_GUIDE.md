## 🎨 Color Scheme

### Status Colors
- **🟢 Green** (#10B981): Normal/Healthy
- **🟡 Yellow** (#F59E0B): Warning
- **🔴 Red** (#EF4444): Critical

### UI Colors
- **Primary Gradient**: Purple (#764BA2) → Blue (#3B82F6)
- **Background**: Gradient overlay
- **Cards**: White with glassmorphism
- **Text**: Dark gray (#1F2937)

## 🎬 Animation Guide

### Live Indicator
- **Pulse**: Slow pulsing animation (3s cycle)
- **Color**: Red (#EF4444)
- **Position**: Top-right corner

### Alert Banner
- **Animation**: Slide in from top
- **Duration**: 0.3s
- **Trigger**: When fault detected

### Metric Cards
- **Hover**: Scale up (105%)
- **Duration**: 300ms
- **Shadow**: Increases on hover

### Progress Bars
- **Animation**: Smooth width transition
- **Duration**: 500ms
- **Trigger**: On data update

## 📱 Responsive Breakpoints

### Desktop (1024px+)
- 3-column grid for metrics
- Full navigation visible
- Side-by-side layout

### Tablet (768px - 1023px)
- 2-column grid for metrics
- Condensed navigation
- Stacked layout

### Mobile (< 768px)
- Single column layout
- Hamburger menu (future)
- Stacked cards
- Touch-friendly buttons

## 🎭 User Experience Flow

### 1. Landing
```
User opens app → Sees dashboard → Data loads → Live indicator appears
```

### 2. Monitoring
```
Data updates every 3s → Cards animate → Status changes color
```

### 3. Alert
```
Fault detected → Banner slides in → User sees alert → Can click service centers
```

### 4. Navigation
```
User clicks tab → Smooth transition → New content loads → Maintains state
```
